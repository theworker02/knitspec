# knitspec

Knit color spec values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/knitspec/

## Install / run

```bash
git clone https://github.com/theworker02/knitspec.git
cd knitspec
node src/cli.js
node --test
```
